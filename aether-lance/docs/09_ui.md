# 09. UI・UX仕様

## 1. 画面遷移

```
Boot ──(入力)──▶ Title ──▶ MainMenu ─┬─ ARCADE ──▶ DifficultySelect ──▶ Game ⇄ Pause
                  ▲  (30秒放置)       │                                  │
                  │  ▼                 │                                  ├─▶ StageClear ─▶ Game（次のステージ）
                  │ AttractDemo        │                                  ├─▶ GameOver ─▶ (CONTINUE) Game
                  │                    │                                  │             └▶ NameEntry ─▶ Ranking ─▶ Title
                  │                    │                                  └─▶ Ending ─▶ Credits ─▶ (LOOP 2) Game / NameEntry
                  │                    ├─ PRACTICE ──▶ PracticeSelect ──▶ Game
                  │                    ├─ BOSS RUSH ──▶ DifficultySelect ──▶ Game
                  │                    ├─ RANKING
                  │                    ├─ OPTIONS ──▶ (各タブ) ──▶ KeyConfig
                  │                    └─ CREDITS
                  └──────────────────── (Esc / キャンセル) ◀─────────────
```

## 2. UIの共通規則

- **操作:** すべてのメニューは、キーボード（上下・決定・キャンセル）、ゲームパッド、マウス（ホバーで選択、クリックで決定）、タッチ（タップで選択と決定）のどれでも操作できる。
- **カーソル:** 選択中の項目の左に、小さなケストレルのアイコン（8×6）を表示し、左右に2px揺らす。項目の文字は白（N8）、それ以外は灰色（N5）。選択が移ったら `menu_move`。
- **遷移:** 黒フェード20f。決定したら `menu_confirm`、戻るときは `menu_cancel`。
- **キーリピート:** 押し続けると、24f後から6fごとにリピートする。
- **確認ダイアログ:** 破壊的な操作（記録の消去、ゲームの中断）は「はい / いいえ」の確認を出す。既定の選択は「いいえ」。
- **文字:** 英語の見出しは `font8`（ゲーム解像度）、日本語の説明文はUIオーバーレイ（DotGothic16）。すべての文字列は `i18n` のキーで参照する（→§9）。
- **安全領域:** スマートフォンのノッチやホームバーを避けるため、`env(safe-area-inset-*)` の分だけUIを内側に寄せる。

## 3. 各画面

### 3.1 Boot

- 黒い背景、中央に小さなロゴ、読み込みのプログレスバー（アトラスの生成、SEの事前レンダリング、背景の生成、フォントの読み込み）。
- 読み込みが終わったら「CLICK / TAP / PRESS ANY KEY」を60f周期で点滅させる。入力されたら、オーディオを有効にしてTitleへ。
- 初回起動時だけ、下に小さく「音が出ない場合は、マナースイッチをオフにしてください（iPhone）」を表示する。

### 3.2 Title

- 背景: ST1の惑星の夕景（L0〜L2を流用し、ゆっくりスクロールさせる）。15秒ごとにケストレルが画面を横切り、光の軌跡を残す。
- ロゴの演出（→07 §10）のあと、「PRESS START」を点滅させる。上部にハイスコア、右下にバージョン番号（`v1.0.0`）と「© 2026」。
- 決定でMainMenuへ。30秒何も入力しなかったら、AttractDemo（デモプレイ）へ［SHOULD］。

### 3.3 AttractDemo［SHOULD］

- 内蔵のリプレイ（ST1の最初の90秒。開発者のプレイを録画した入力ログ）を再生する。画面の下に「DEMO PLAY」と「PRESS START」。何か入力したらTitleへ戻る。
- リプレイの入力ログは決定性の検証にも使う（→10 §3）。

### 3.4 MainMenu

| 項目 | 説明（オーバーレイに表示） | 解放 |
|---|---|---|
| ARCADE | 全6ステージに挑む | 最初から |
| PRACTICE | 到達したステージを練習する | 最初から |
| BOSS RUSH | ボスとの連戦（タイムアタック） | 1周クリア（未解放のときは「? ? ?」と表示し、選べない） |
| RANKING | ハイスコア | 最初から |
| OPTIONS | 設定 | 最初から |
| CREDITS | クレジット | 最初から |

### 3.5 DifficultySelect

- 4枚のカード（EASY / NORMAL / HARD / ORDEAL）を横に並べる。カードには名前、短い説明（「初めての人に」「標準」「歯応えを求める人に」「最後の試練」）、主な違い（残機、地形の扱い）を表示する。ORDEALは解放されるまで鍵のアイコンを表示する。
- カードの下で、復活方式を選ぶ: `IN-PLACE`（その場で復活。既定）/ `CHECKPOINT`（チェックポイントから再開）。
- 決定したら、ステージ1の紹介へ。

### 3.6 PracticeSelect

| 項目 | 選択肢 |
|---|---|
| ステージ | 到達したことのあるステージ（1〜6）、周（2周目に到達していれば選べる） |
| 開始位置 | 開始 / CP1 / CP2 / CP3（ボス） / 中ボスのみ / ボスのみ |
| 武器タイプとLv | PULSE / FAN / RAY、Lv1〜5 |
| サブ武器 | なし / BOMB Lv1〜2 / SEEKER Lv1〜2 |
| ドローン | 0〜4、陣形 |
| バリア | なし / あり |
| 難易度 | EASY〜（解放済みのもの） |
| 無敵 | OFF / ON |

- 既定値は「そのステージに通常到達したときの標準的な装備」（→03 §5.7）。

### 3.7 Game（HUD → §5）

### 3.8 Pause

- ゲーム画面を暗くし（alpha 0.6）、中央にメニューを出す: `RESUME` / `OPTIONS`（AUDIO、VIDEO、ACCESSIBILITYのみ）/ `CONTROLS`（操作方法の一覧を表示）/ `RETRY`（PRACTICEのみ）/ `QUIT TO TITLE`（確認あり）。
- ポーズ中は、現在の装備（武器、Lv、サブ、ドローン、陣形、速度）と、ステージの進捗バーを表示する。
- 再開したら、30fの「READY」表示のあと、ゲームが動き出す（入力を再び受け付けるまでの猶予）。

### 3.9 StageClear

- 「STAGE CLEAR」の文字が左右から滑り込む（20f）。
- ボーナスを1行ずつ表示する（30f間隔）: STAGE CLEAR / NO MISS / BOSS TIME / ITEMS / （2周目なら ×1.5）/ TOTAL。各行の数値は `tally` の音とともにカウントアップする。
- 決定ボタンで集計を早送りできる。最後に「NEXT STAGE ▶」を表示し、フェードして次のステージの紹介へ。

### 3.10 GameOver

- 「GAME OVER」の文字が1文字ずつ上から落ちてくる。
- コンティニューできる場合: 「CONTINUE? 10」のカウントダウン（60fごとに1減り、`countdown` が鳴る）。決定ボタンでコンティニューする。キャンセルボタンで1秒ずつ早送りする。
- コンティニューできない場合、またはカウントが0になった場合: ランキング入りしていればNameEntryへ、していなければTitleへ。

### 3.11 NameEntry

- 3文字の名前を入力する。使える文字: A〜Z、0〜9、`. - ! ? ★ ♥`、空白、`END`。
- 操作: 上下で文字を切り替え、決定で次の文字へ、キャンセルで1文字戻る。キーボードなら直接タイプしてもよい。タッチは文字のグリッドをタップする。
- 制限時間30秒（残り時間を表示する）。時間切れになったら、その時点の文字で確定する。
- 前回入力した名前を初期値にする。

### 3.12 Ranking

- タブ: EASY / NORMAL / HARD / ORDEAL / BOSS RUSH。左右で切り替える。
- 上位10件: 順位、名前、スコア（BOSS RUSHはタイム）、到達（例: `2-4`、`ALL`、`ALL 2`）、日付、フラグ（`C×n`、`CP`、`ASSIST`）、主に使った武器のアイコン。
- 今回ランクインした行を点滅させる。

### 3.13 Ending / Credits

- エンディング（→01 §3.3）は、最大90秒の演出。決定ボタンの長押し（1秒）でスキップできる（押している間、ゲージを表示する）。
- クレジット（`src/content/credits.ts` で編集できる）: 
  - `GAME DESIGN / PROGRAM / GRAPHICS / MUSIC / SOUND — <作者名>`（既定値は `YOU`。作者が自分の名前に書き換える）
  - `DEVELOPED WITH Claude Code`
  - `FONT: DotGothic16 (SIL OFL 1.1)`
  - `SPECIAL THANKS: AND YOU, PILOT.`
- 最後にプレイの統計（スコア、プレイ時間、ミス数、撃破数、命中率）を表示する。

### 3.15 KeyConfig

- アクションの一覧に、主キーと副キーを表示する。項目を選んで決定すると「キーを押してください（Escでキャンセル）」になり、次に押したキーを割り当てる。
- ほかのアクションに使われているキーを割り当てたら、そちらと入れ替える（重複させない）。
- ゲームパッドも同様に設定する。パッドが接続されていなければ「ゲームパッドを接続してください」と表示する。

## 4. ゲーム中の演出UI

### 4.1 ステージ紹介

→ 05 §1。「STAGE 1」は `font8` の×3。英語名は×2。日本語名とブリーフィングはUIオーバーレイ。

### 4.2 WARNING

- 180f。画面の上下から赤と黒の斜めストライプの帯（高さ24px）が流れ込み、中央に「WARNING」（×3、赤 R3 ではなく警告色 O4/O5 を使う。敵弾の色と区別するため）、その下にボス名（例: 「WARDEN-CLASS CARRIER」）。サイレンが鳴る。フラッシュ軽減モードでは、点滅をフェードに置き換える。

### 4.3 そのほか

- 陣形名、効果名、「1UP」、至近距離ボーナスの「×2」などのポップアップは、自機の上（y −20）に表示する。
- チェックポイントの通過時は、画面の右上に「CHECKPOINT」を小さく表示する（60f）。

## 5. HUD

### 5.1 レイアウト（480×270上の座標）

| 要素 | 位置 | 内容 |
|---|---|---|
| 1Pのスコア | 上 (4, 2) | `1P` + 10桁（N8）。カウントアップ表示 |
| ハイスコア | 上 中央揃え (240, 2) | `HI` + 10桁（N6）。現在のスコアが上回ったら、金色にして同期する |
| ステージ表示 | 上 右揃え (476, 2) | `1-B`（周-セクション）。PRACTICEでは `PRACTICE` |
| ボスのHPバー | (130, 14)、幅220 | ボス戦のときだけ（→06 §1.2） |
| 残機 | 下 (4, 258) | 自機アイコン（8×6）×残機数（6以上は「アイコン ×n」） |
| 速度 | 下 (60, 258) | `SPD` + 4マスのゲージ。切り替えのとき点滅する。タッチ操作中は非表示 |
| 武器 | 下 (120, 258) | タイプのアイコン（P/F/R）+ `Lv3` + Lvを5マスで表示。サブ武器のアイコン（B/S）とLv |
| ドローン | 下 (220, 258) | 4つの丸（取得済みは塗り、未取得は輪郭）+ 陣形名（WING / TRAIL / ORBIT） |
| ドライブゲージ | 下 (320, 258)、幅100 | `DRIVE` + ゲージ。満タンで金色に脈動し「READY」と表示。発動中は減っていく |
| バリア | 下 (440, 258) | ⬡ × HP |

- HUDの背景: 上下それぞれ、黒（N0）の alpha 0.45 の帯。
- 自機が帯から24px以内に来たら、HUD全体の alpha を30%に下げる（10fで変化）。
- デバッグモードでは、右上にFPS、エンティティ数、ランクを重ねて表示する。

## 6. タッチUI

### 6.1 横持ち

```
┌───────────────────────────────────────────────┐
│                                         [II]  │ ← ポーズ（右上、40px）
│                                               │
│      （画面のどこでもドラッグ = 自機の移動）       │
│                                        (FORM) │ ← 52px
│                                     ( DRIVE ) │ ← 72px（右下）
└───────────────────────────────────────────────┘
```

- ボタンは半透明（alpha 0.35。押している間は0.7）。ボタンの上ではドラッグを開始しない。
- 指を置いた場所に、うっすらと円（半径24px）を表示し、操作していることを分からせる。
- 左利きのオプションでは、ボタンを左側に配置する。

### 6.2 縦持ち

- ゲーム画面を上部に幅いっぱいで表示する（16:9）。下の余白全体をドラッグパッドにし、その下部にDRIVEボタンとFORMボタンを並べる。
- 初回だけ「横向きがおすすめです」と表示する（タップで閉じる）。

### 6.3 そのほか

- ゲーム中は、ページのスクロール、ピンチによる拡大、長押しのメニュー、ダブルタップによる拡大を無効にする（`touch-action: none`、`user-select: none`、`-webkit-touch-callout: none`）。
- Androidの戻るボタン（`popstate`）はポーズとして扱う。

## 7. 画面とウィンドウ

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no">`
- ゲーム画面は常に中央に置き、余白は黒にする。
- フルスクリーンボタン（PCとAndroid）: Fullscreen APIを使い、可能なら `screen.orientation.lock('landscape')` を試す（失敗しても何もしない）。
- ウィンドウのサイズが変わったら、拡大率を計算し直す。

## 8. セーブデータ

```ts
interface SaveV1 {
  version: 1;
  settings: {
    lang: 'ja' | 'en'; shotMode: 'hold' | 'toggle'; touchSensitivity: number; touchLayout: 'right' | 'left';
    touchAlwaysFire: boolean; vibration: boolean;
    keys: Record<Action, [string, string | null]>; pad: Record<Action, number>; analogMove: boolean;
    scaleMode: 'integer' | 'fit' | 'stretch'; scaleFilter: 'sharp' | 'soft'; crt: 'off' | 'light' | 'strong';
    scanline: number; bloom: number; interpolate: boolean; quality: 'auto' | 'high' | 'low'; showFps: boolean;
    volMaster: number; volBgm: number; volSfx: number;
    shake: 'off' | 'half' | 'full'; flashReduce: boolean; bulletEmphasis: boolean; showHitbox: boolean;
    bgDim: number; gameSpeed: 100 | 90 | 80;
  };
  records: Record<Difficulty | 'bossrush', RankEntry[]>;   // 各10件
  progress: { reachedStage: Record<Difficulty, number>; loop2Reached: boolean; cleared: Record<Difficulty, 0 | 1 | 2>; bossRushUnlocked: boolean; ordealUnlocked: boolean; heardSongs: string[]; };
  stats: { playTimeSec: number; kills: number; deaths: number; credits: number; weaponUse: Record<WeaponType, number>; };
  lastName: string;
  achievements?: string[];
  replays?: ReplayMeta[];                                   // [SHOULD] 各難易度のベストのみ
}
interface RankEntry { name: string; score: number; reach: string; date: string; flags: string[]; weapon: WeaponType; }
```

- キー: `aetherlance.save.v1`。リプレイの本体は `aetherlance.replay.<id>` に別に保存する（入力ログをRLE圧縮してbase64で。1プレイあたり約30KB以下）。
- 読み込みのとき、`version` を見て順番にマイグレーションする。壊れたデータ（JSONの解析失敗、型の不一致）は、該当する部分だけ既定値に戻す（全消去しない）。
- 保存のタイミング: 設定の変更時、ステージクリア時、ゲームオーバー時、ランキングの登録時。ゲーム中には保存しない（ヒッチを避けるため）。

## 9. 多言語

- `src/i18n/ja.ts` と `src/i18n/en.ts` に、同じキーの集合を持たせる（キーの欠けは単体テストで検出する）。
- 固有名詞（ステージ名、ボス名、武器名）は、英語の大文字を両言語で共通に使う。日本語版では、ステージの副題（「軌道環」など）と説明文だけを日本語にする。
- テキストは文字数が変わっても崩れないように、オーバーレイでの折り返しと、はみ出したときの縮小に対応する。

## 10. アクセシビリティのまとめ

| 配慮 | 実装 |
|---|---|
| 操作の自由 | すべてのキーとボタンを再割り当てできる。押しっぱなしの連射と切替式。タッチの左右反転 |
| 光過敏性 | フラッシュ軽減（フラッシュの上限、3Hz以上の点滅の禁止）、画面の揺れの調整 |
| 視認性 | 弾の強調表示、当たり判定の表示、背景の暗さ。敵弾は色だけでなく、形と白い芯でも区別できる（色覚の多様性への配慮） |
| 難しさ | EASY（地形でミスにならない、残機5、コンティニュー無制限）、PRACTICE（無敵あり）、ゲーム速度80〜90% |
| 音 | 重要な危険にはすべて視覚的な予告があり、音が聞こえなくてもプレイできる |

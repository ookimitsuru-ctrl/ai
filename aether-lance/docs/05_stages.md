# 05. ステージ仕様

## 1. ステージの共通構造

| 段階 | 時間 | 内容 |
|---|---|---|
| ステージ紹介 | 240f | 画面中央に「STAGE n」（大きく）+ 英語名 + 日本語名 + 1行ブリーフィング。文字を左から1文字ずつ表示し（2f/文字）、120f表示したらフェードアウトする。この間に自機が進入する。BGMは紹介の開始と同時に始める |
| 道中 | 約3分20秒〜3分40秒 | セクションA〜G。チェックポイントは CP1（約1:30）、CP2（中ボスの後）、CP3（ボスの直前） |
| 中ボス | 30〜45秒 | スクロールは停止するか減速する。時間制限を過ぎると退場する（撃破ボーナスなし） |
| WARNING | 180f | BGMをフェードアウトし、警告のサイレン、赤い帯が上下から流れ、中央に「WARNING」とボス名を表示する（→09 §4.6） |
| ボス戦 | 60〜120秒（目安） | 時間制限を過ぎるとボスは撤退する（ボーナスなし。ステージはクリア扱い） |
| クリア | 約300f | ボス撃破の演出 → 「STAGE CLEAR」→ ボーナスの集計 → フェードして次のステージへ |

- ステージデータの時刻は**フレーム数**で記述する（下表では読みやすさのため m:ss で表す。1秒 = 60f）。
- 中ボスとボスの戦闘中は、タイムラインの時刻を進めない（`waitUntil: 'bossDefeated'`）。下表の中ボス以降の時刻は「中ボスを最短の目安時間で倒した場合」の値である。
- 「（編B: ARMS）」は編隊ボーナスで出るアイテム、「（キャ: WISP）」はキャリア敵、「（配: DRIVE）」は配置アイテムを表す。

## 8. 地形の制作方法

- 地形は「**地形セグメント**」の列で記述し、ロード時に16×16タイルの列（高さ17タイル = 272px。縦カメラのある区間はそれ以上）へ変換（ベイク）する。手作業で長いASCIIマップを書かない。
- セグメントの型（→11 §2）:

| 型 | パラメータ | 内容 |
|---|---|---|
| `none` | length | 地形なし |
| `floor` | length, height, [rough] | 床（下からの高さ。rough は凹凸の振幅） |
| `ceil` | length, height | 天井 |
| `corridor` | length, floorH, ceilH | 床と天井 |
| `ramp` | length, from, to, which | 床か天井の高さを線形に変える（斜面タイルを自動で選ぶ） |
| `pillars` | length, interval, width, gap, alternate | 交互の柱 |
| `islands` | length, list | 浮遊する島（ST4） |
| `breakable` | x, y, w, h, hp, regen? | 破壊可能なブロック（ST2の結晶、ST3の肉壁） |
| `crystal` | x, y, w, h | 反射面のタイル |
| `conveyor` | x, y, w, which, speed | コンベア |
| `rhythm` | x, y, w, h, phase | 共鳴する壁（ST6） |
| `wave` | length, amp, period | 蠕動する壁（ST3。描画と判定を毎フレーム、オフセットで動かす） |

- オートタイリング: 固体タイルの4近傍と斜め4近傍から、47種のブロブタイルを自動選択する。タイル画像はステージのテーマごとに手続き生成する（→07 §5）。
- 地上の敵のアンカーは「セグメントの開始位置からの相対座標」で指定し、地形の表面の高さに自動でスナップさせる（`snap: 'floor' | 'ceil'`）。

# 06. 中ボス・ボス仕様

## 1. 共通仕様

### 1.1 出現

- **中ボス:** 警告の演出はない。BGMは道中の曲のまま。登場の60fは無敵で、登場が終わったらHPバーを表示する。
- **ボス:** WARNING（180f）→ 登場演出（120〜240f。無敵）→ ボスBGM開始 → HPバーを表示する。
- 登場演出の途中でも自機は自由に動ける。ボスは登場中に攻撃しない。

### 1.2 HPバー

- 上HUDのすぐ下（y=14）、中央に幅220px・高さ4pxで表示する。ボス名を小さく左に添える。
- 値は「現フェーズでダメージが通る全パーツのHP合計」。フェーズの区切りは目盛りで示す。
- ダメージを受けた分は白く残し、20fかけて減らす（減少アニメーション）。

### 1.3 パーツ

- ボスは複数のパーツで構成する。各パーツは `hp`、`armored`（常時 / 条件付き）、`hitbox`、`onDestroy` を持つ。
- 破壊したパーツは「残骸のスプライト」に差し替え、煙と火花を出し続ける（ボス撃破まで）。
- パーツを破壊すると、ヒットストップ4f、medium爆発×3、パーツの点数、画面の揺れ +0.35。

### 1.4 フェーズ移行

- HPの閾値またはパーツの破壊で、次のフェーズへ移行する。
- 移行時の演出: 60fのあいだ無敵、画面上の敵弾をSTAR CHIPに変える、ボスが赤く明滅する、SE `boss_phase`、画面の揺れ +0.3。

### 1.5 撃破

1. ヒットストップ8f
2. スローモーション60f（3フレームに1回だけ更新する）。画面上の敵弾はすべてSTAR CHIPに変わる
3. 連鎖爆発（ボスの各部位で、medium〜largeの爆発を120fのあいだ6fごとに）。BGMは停止する
4. 最後の大爆発: 白フラッシュ（alpha 0.8 → 0、30f）、画面の揺れ 1.0、ショックウェーブの歪み、SE `boss_die`
5. ボスの破片（大きな残骸スプライトが回転しながら飛び散る）
6. 撃破点を中央に大きくポップアップ表示し、勝利ジングル `jingle_clear` を鳴らす → ステージクリアの集計へ

### 1.6 時間制限

- 制限時間を過ぎたボスは撤退する（画面外へ高速で離脱する）。撃破点とBOSS TIMEボーナスは入らない。中ボスも同様。
- 残り10秒になったら、HPバーを点滅させる。

### 1.7 HPの設計基準

- 想定DPS（NORMAL、標準的な装備、命中率50%で計算）: ST1 約35、ST2 約50、ST3 約65、ST4〜6 約80〜90。
- 目標の撃破時間: 中ボス20〜30秒、ボス60〜90秒、最終ボス合計120〜150秒。

| 溶接の薙ぎ | アームを x=250 まで伸ばし、炎の円錐（長さ64、30°）を上下に60fかけて振る（予告: 青い火花30f） |
| 炉心 | 90fごとに自機狙い3-way（ORB 1.8） |

**フェーズ2（両アームを破壊、または60秒経過）**

- **圧殺:** 上下のプレートが迫り、高さ64pxの隙間だけを残す。隙間の中心yを60f前に明るい線で予告し、12fで叩きつけ、60f保持し、40fで戻る。隙間の位置は 135 → 80 → 190 →（予告開始時の自機のy）の順に繰り返す。
- プレートが開いている間だけ、炉心が80fごとに12-wayのORBリングを撃つ。

**フェーズ3（炉心HP 30%未満）**

- プレートが閉じた位置で止まり、通路は高さ180px（y 45〜225）になる。下のプレートの表面がコンベアになり、自機を左へ押す（vx −0.6。画面の左端には挟まれず、クランプされるだけで安全）。
- 炉心: 4本腕の渦（1発ごとに6°、5f間隔、PELLET 1.6）と、自機狙いの連射を交互に。
- 天井からスクラップの雨（影で予告）。

- **2周目:** 圧殺の保持を40fに短縮し、隙間を2回連続で入れ替える。
- **撃破演出:** 炉心が赤熱し（60f）、連鎖爆発 → 溶鉄の閃光 → 静寂の中で、背景の工廠の照明が奥から順に消えていく（120f）。

### B6 THE CHOIR（ザ・コーラス） — ST6 最終ボス

- **時間制限なし。** 3つの形態。BGMはBPM 150（1拍 = 24f、1小節 = 96f）で、攻撃はすべて拍に同期する。
- 点数: 形態1 50,000、形態2 70,000、形態3 80,000（合計200,000）。

**形態1「HALO（光輪）」**

| 項目 | 値 |
|---|---|
| 構成 | 中心の球体コア（64×64、(360, 135)）、外輪（半径90）のノード×8（各HP 80）、内輪（半径50）のノード×4（各HP 120） |
| 回転 | 外輪は時計回りに0.6°/f、内輪は反時計回りに1.0°/f |
| 装甲の順序 | 外輪のノードを全滅させる → 内輪のノードにダメージが通るようになる → 内輪を全滅させる → コア（HP 1600）が露出する |

| 攻撃 | 内容 |
|---|---|
| 外輪 | 毎拍、ノードの1つ（回転順）が自機狙い3-way（PELLET 1.8） |
| 内輪 | 毎小節の1拍目に、8-wayのリング（小節ごとに回転） |
| コア | 1拍目と3拍目: 16-wayのORBリング（1.5） ／ 2拍目と4拍目: 自機狙いのNEEDLE 3-way（2.4） |

- 移行: コアにひびが入り、光の柱が立ち、180fかけて変形する（無敵）。

**形態2「CANTOR（詠唱者）」**

| 項目 | 値 |
|---|---|
| 構成 | 翼を持つ人型（120×160、x=370）。本体 HP 3600（翼が閉じているときはダメージ×0.5、開いているときは×1.0）。翼×2（各HP 400。壊さなくてもよい。破壊すると常に開いた状態になる） |
| 翼 | 4小節のフレーズのうち、3〜4小節目に開く |

| 攻撃 | 内容 |
|---|---|
| **旋律弾** | **BGMのリードの音符イベントごとに**、口元から1発撃つ。角度 = 180° + (音高 − 基準音高) × 4°、速度1.8（音が高いほど上へ飛ぶ）。弾の並びが旋律の形を描く。1拍あたり最大8発 |
| 音波 | 毎小節の1拍目に、自機方向へWAVE ARC（中心角60°）。隙間の位置を左右交互に変える |
| 羽根 | 翼が開く小節の頭に、羽根のNEEDLE 7-way |
| 第2節（HP 50%以下） | 旋律弾を上下対称の2本に、音波を2重に |

- 移行: 歌が途切れ、画面が暗転し、音楽が止まる。

**形態3「SILENCE（沈黙）」**

| 項目 | 値 |
|---|---|
| 構成 | 小さな核（40×40、HP 1500）。高速で動く |
| 音 | BGMはなく、心音だけ（HPが減るほど心拍が速くなる） |
| 特殊ルール | 自機のドライブゲージが毎フレーム+1ずつ自動で増える（100fで満タン）。ドライブ中は、核へのダメージが×2になる。プレイヤーにランスドライブで決着をつけさせる演出 |

| 攻撃 | 内容 |
|---|---|
| 突進 | 予告線（40f）の上を高速で突進する。通った軌跡に4fごとにPELLETを置き、置いた弾は軌跡に垂直な方向へ0.8px/fでゆっくり広がる |
| 決着 | 撃破すると、画面全体が白く染まり、止まっていた音楽が長調の和音で解決する → エンディングへ |

- **2周目:** 形態1の外輪が毎拍5-wayに、形態2の旋律弾が速度2.2に、形態3の軌跡の弾が2倍に。

## 0. この指示書について

### 0.1 目的

本書は、ブラウザで遊べる横スクロールシューティングゲーム『AETHER LANCE』を、**追加の質問なしで最高品質のまま完成させる**ための設計・実装指示書である。仕様上の判断はすべて本書の中で決めてある。実装者は本書に従って作り、本書に書かれていない細部は「§0.6 判断に迷ったときの優先順位」に従って決める。

### 0.2 作品の位置づけ

- 1980年代後半から90年代のアーケード横スクロールSTG（『グラディウス』に代表されるジャンル）の手触りを、現代のブラウザ技術で作り直す。目指す手触りは次の4つ。
  - 地形との駆け引き
  - パワーアップで自機を育てる楽しさ
  - 敵配置を覚えて上達する快感
  - 画面を圧倒する巨大ボス
- **特定作品の再現や移植ではなく、完全なオリジナル作品とする。** 名称、キャラクター、ステージ、ボス、楽曲、システム上の固有要素は一切流用しない（→ [01 §5 IPガイドライン](01_concept.md#5-ipガイドラインmust)）。

### 0.4 用語と単位

| 用語・記号 | 定義 |
|---|---|
| **f（フレーム）** | ゲームロジックの1ステップ = 1/60秒。時間に関する数値は原則 f で表す（60f = 1秒） |
| **px** | 内部解像度（480×270）上の1ピクセル。実画面のピクセルではない |
| **px/f** | 速度。1フレームあたりの移動ピクセル数 |
| **座標系** | 原点は画面左上。x は右が正、y は下が正 |
| **角度** | 0° = 右（自機の前方）。y軸が下向きなので、**時計回りが正**（90° = 真下、−90° = 真上、180° = 左） |
| **ワールド座標 / スクリーン座標** | 地形はワールド座標で定義し、カメラのスクロール量を引いてスクリーン座標にする。敵・弾・自機は特記がない限りスクリーン座標で管理する（→02 §6） |
| **HP / ダメージ** | 敵の耐久値。基準はPULSE Lv1の1発 = 1.0 ダメージ |
| **ランク** | 動的難易度の内部値（0〜100）（→03 §8） |
| **キャリア** | 倒すとアイテムを落とす敵。アイテムの色で発光する（→03 §5.6） |
| **テレグラフ（予告）** | 危険な攻撃の前に出す視覚・聴覚の予兆 |
| **周（ループ）** | 全6ステージを1巡すること。2周目は難度が上がる |

### 0.5 優先度ラベル

| ラベル | 意味 |
|---|---|
| **[MUST]** | 必須。欠けたら未完成とみなす |
| **[SHOULD]** | 強く推奨。品質目標の達成に必要。工数が非常に大きい場合だけ M5 以降に回してよい |
| **[COULD]** | 余裕があれば実装する。削っても製品として成立する |

ラベルのない仕様は **[MUST]** として扱う。

### 0.6 判断に迷ったときの優先順位

本書に書かれていない細部は、上から順に優先して決める。

1. **フェアネス**: 初見でも、予告を見て反応すれば避けられること。理不尽な死はあってはならない
2. **レスポンス**: 入力してから画面に反映されるまでの遅延を最小にする。操作感を損なう演出はすべて削る
3. **視認性**: 敵弾、自機、当たり判定が、どの背景の上でも一目で分かること
4. **手応えと爽快感**: ヒット、撃破、取得のたびに、音・光・揺れのフィードバックを返す
5. **美しさ**: スクリーンショット1枚がそのまま宣材として通用する画作り
6. **実装の単純さ**: 1〜5に差が出ないなら、単純な実装を選ぶ

### 0.7 決定事項サマリ（1ページ版）

| 項目 | 決定 |
|---|---|
| タイトル | **AETHER LANCE**（エーテルランス） |
| ジャンル | 横スクロールシューティング、1人用 |
| ボリューム | 全6ステージ×2周。1周およそ25〜30分。1ステージ3.5〜4.5分 |
| 内部解像度 | 480×270（16:9）。整数倍スケーリング、ピクセルアート |
| ロジック更新 | 60Hz固定タイムステップ。決定的（同じ入力からは同じ結果） |
| 技術 | TypeScript + Vite。ランタイム依存ライブラリはゼロ。Canvas2Dで描画し、WebGL2でポストエフェクト |
| アセット | 画像も音もすべてコードで生成する。外部ファイルは使わない（フォントのみ Google Fonts の DotGothic16 を許可） |
| 音 | WebAudioの自作シンセとMMLシーケンサ。BGM 16曲、SE 50種以上 |
| 自機 | 試作迎撃機 AL-7「ケストレル」。1発で撃墜（バリア所持時を除く）、速度4段階 |
| メイン武器 | 3種（PULSE / FAN / RAY）× Lv1〜5。Lvは武器間で共通 |
| サブ武器 | 2種（GRAVITY BOMB / SEEKER）× Lv1〜2 |
| 随伴機 | ドローン「ウィスプ」最大4機。陣形は WING / TRAIL / ORBIT の3種 |
| 防御 | バリア「イージス」3HP（弾、体当たり、地形接触を防ぐ） |
| 必殺 | ランスドライブ: ゲージ満タンで発動。弾消し衝撃波と6秒間の火力強化、スコア2倍 |
| パワーアップ方式 | 色付きクリスタルを取ると即時に強化される。武器タイプは回転チップで選ぶ。配置は固定 |
| ミス時 | その場で復活。武器Lv−1、ドローンは散らばって回収可能、バリア消失。CHECKPOINT方式も選択できる |
| 難易度 | EASY / NORMAL / HARD / ORDEAL（解放制）+ 動的ランク |
| モード | ARCADE、PRACTICE、BOSS RUSH（解放制）、SCORE ATTACK［COULD］ |
| 入力 | キーボード、ゲームパッド、タッチ（スマホ横持ち・縦持ち）。すべてファーストクラスで対応 |
| 配布 | ① 単一HTMLファイル（そのまま開ける、Artifactとして公開できる） ② GitHub Pages ③ PWA（ホーム画面に追加、オフライン動作） |
| 言語 | 日本語 / 英語（ブラウザの言語設定で自動選択し、オプションで切り替え可能） |
| 保存 | localStorage（設定、ハイスコア、解放状況、統計、リプレイ［SHOULD］） |
| 配置場所 | リポジトリ内の `aether-lance/`（本書は `aether-lance/docs/`） |

### 0.8 変更管理

- 本書の数値は**初期値**であり、バランス調整で変えてよい。ただし数値はすべて `src/data/balance.ts` などのデータファイルに集約し、コード中に直書き（マジックナンバー）しない。
- 調整で数値を変えたら、本書の該当表も同じコミットで更新する。
- 仕様そのものを変えるとき（システムの追加・削除）は、本書を先に更新してから実装する。
